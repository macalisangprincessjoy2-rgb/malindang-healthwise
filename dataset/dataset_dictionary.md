# Health Assessment Dataset

This dataset was created for the Malindang Highlands Web-Based Expert System with Integrated Decision Support for Preliminary Health Assessment and Healthcare Referral.

## Purpose
The dataset supports preliminary health assessment and referral classification for residents in highland areas such as Owayan and Hoyohoy, especially in Don Victoriano and Tangub City.

## File
- `health_assessment_dataset.csv`

## Columns

- `patient_id`: unique patient or case identifier
- `full_name`: sample name for demonstration purposes only
- `age`: age of the patient
- `municipality`: municipality location
- `barangay`: barangay or local area
- `address`: resident address or barangay location
- `fever`: 1 if fever is present, otherwise 0
- `cough`: 1 if cough is present, otherwise 0
- `difficulty_breathing`: 1 if difficulty breathing is present, otherwise 0
- `severe_fatigue`: 1 if severe fatigue is present, otherwise 0
- `chest_pain`: 1 if chest pain is present, otherwise 0
- `diarrhea`: 1 if diarrhea is present, otherwise 0
- `vomiting`: 1 if vomiting is present, otherwise 0
- `dehydration`: 1 if dehydration is present, otherwise 0
- `loss_of_appetite`: 1 if loss of appetite is present, otherwise 0
- `body_weakness`: 1 if body weakness is present, otherwise 0
- `stomach_pain`: 1 if severe stomach pain is present, otherwise 0
- `intestinal_worms`: 1 if intestinal worms are suspected, otherwise 0
- `cold_exposure`: 1 if extreme mountain cold is reported, otherwise 0
- `dense_fog`: 1 if dense fog exposure is reported, otherwise 0
- `smoke_exposure`: 1 if prolonged firewood smoke exposure is reported, otherwise 0
- `chronic_cough`: 1 if a cough has persisted, otherwise 0
- `asthma`: 1 if asthma or wheezing is reported, otherwise 0
- `symptom_text`: free-text symptom description in Bisaya or mixed language
- `notes`: brief note on the observed condition
- `risk_level`: classification such as Low, Moderate, or High
- `referral_recommendation`: recommended action based on expert-system logic
- `priority`: urgency level used by the decision support system

## Risk classification logic
- `Low`: mild symptoms, routine monitoring
- `Moderate`: moderate symptoms, consult a health professional within 24 hours
- `High`: severe symptoms or emergency signs, immediate referral to hospital or clinic

## Community health context

- **Interior waterborne risks:** Lake Duminagat and Napangan may have limited access to centralized water treatment. Relevant indicators include `kalibanga`, `sigeg kalibanga`, `pagsuka`, `sakit sa tiyan`, and `bitok`.
- **High-elevation respiratory risks:** Gandawan, Lalud, and Petian may experience extreme cold, dense fog, and prolonged firewood-smoke exposure. Relevant indicators include `pirteng bugnawa`, `gabun`, `aso sa dabu-dabu`, `trangkaso`, `hubak`, and persistent cough.

These community categories guide preliminary screening only; they do not establish disease prevalence or replace clinical diagnosis.

## Notes
This is a sample dataset for prototype and thesis demonstration. It is not an actual clinical dataset and should not be used for real medical diagnosis without validation by licensed healthcare professionals.

## Augmented training dataset

`health_assessment_dataset_augmented.csv` is a second file, generated by
`scripts/generate_synthetic_dataset.py`, and is what `ml_module.py` actually
trains and cross-validates the supplementary ML classifier against. It exists
because the 16 curated records above are too small a sample to support any
claim about a trained classifier's accuracy.

It contains all 16 curated rows unchanged, plus 150 additional rows generated
by procedurally sampling symptom/age/location combinations and labeling each
one with the project's own rule-based engine (`health_system.assess_patient`)
— the same engine documented in `docs/rule_base.md`. Generation is seeded
(`SEED = 42`) for reproducibility.

This file adds one column beyond the 27 above:

- `source`: `curated` for the 16 hand-written case narratives, or `synthetic`
  for a generated row. This distinction is load-bearing, not cosmetic — a
  `synthetic` row is a rule-engine-labeled sample used to validate the
  classifier's ability to reproduce the rule engine's own logic across a
  larger, class-balanced sample. It is **not** a claim about real symptom
  co-occurrence or disease prevalence, and should be described that way in
  any write-up that cites the classifier's accuracy.
